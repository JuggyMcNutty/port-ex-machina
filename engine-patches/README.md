# Engine patches

The Surreal Engine fork, as patches: `UPSTREAM-BASE.txt` is the upstream commit
it is pinned to, each `NNNN-*.patch` one fork commit in order, and `optional/`
the profiling hooks that are never committed. `scripts/engine.sh fetch` turns
them into `engine/SurrealEngine`.

What the fork is for, how it is kept and what each patch changes:
[`docs/ENGINE.md`](../docs/ENGINE.md).
